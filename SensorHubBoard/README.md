**SensorHub** – **Sensor Interface Board**  

This board handles the integration of various sensors including temperature, acceleration, gas sensors (CO₂, O₂, ethanol, methane, butane), GPS, and others.  

> ⚠️ Status: Conceptual stage  
> The design and implementation of this board have not yet been carried out. Detailed component selection, schematics, and testing procedures will be added once development starts.
