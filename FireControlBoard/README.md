**FireControlBoard** – **NXP / IXYS (TBD)**  

This board is intended to handle the fire control system, including interfacing with a laser rangefinder and triggering the BB gun turret mechanism.  

> ⚠️ Status: Conceptual stage  
> The design and implementation of this board have not yet been carried out. Component selection, schematics, and software integration will be developed in future stages.
