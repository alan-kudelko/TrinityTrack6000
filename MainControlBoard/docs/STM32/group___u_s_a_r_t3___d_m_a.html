Detailed Description

USART3 low level driver with DMA functionality with dedicated ring buffer.

Note
This module uses modified USART3_IRQHandler in stm32g4xx_it.c to handle USART3 rx interrupts.

void usart3_dma_init ( void )

Initializes USART3 DMA functionality, ring buffers and variables.

Note
This function must be called before using any other USART3 DMA functions. It sets up the necessary buffers and prepares USART3 for DMA operations.

◆ usart3_dma_tx_complete()

void usart3_dma_tx_complete ( void )

Callback function called when USART3 DMA transmission is complete.

Note
This function is called from the HAL_UART_TxCpltCallback when USART3 transmission is complete. It checks if there is more data in the transmit ring buffer and initiates another DMA transmission if needed along with updating the ring buffer pointers and dma_tx_buffer_length variable.
Warning
This function is intended for internal use only.
