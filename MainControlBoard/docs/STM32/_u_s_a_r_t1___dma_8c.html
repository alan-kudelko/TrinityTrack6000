void usart1_dma_copy_from_rx_buffer ( const uint16_t dma_transfer_size)

Copies data from the provided source DMA buffer to the receive ring buffer.

Parameters
dma_transfer_sizeLength of the data to be copied in bytes.
Note
This function is dedicated to process debug terminal incoming data. Which means that it copies data until reaching /r/n sequence. If there is no /r/n sequence in the buffer, no data is copied and the ring buffer is cleared.
Warning
This function is intended for internal use only.

bool usart1_dma_read_data ( uint8_t * dst,
uint8_t * length,
const uint16_t maxLength )

Reads data from the USART1 receive ring buffer into the provided destination buffer.

Parameters
dstPointer to the destination buffer where received data will be copied.
lengthPointer to a variable where the length of the copied data will be stored.
maxLengthMaximum length of data to be read in bytes.
Returns
true if data was successfully read, false if no complete command was available.
Note
This function copies data until reaching a /r/n sequence. If there is no /r/n sequence in the buffer, no data is copied and the ring buffer is cleared.
Warning
This function is dedicated to process debug terminal incoming data.

◆ usart1_dma_rx_complete()

void usart1_dma_rx_complete ( const uint16_t dma_transfer_size)

Callback function called when USART1 DMA reception is complete.

Parameters
dma_transfer_sizeSize of the data transferred by DMA in bytes.
Note
This function is called from the HAL_UART_RxCpltCallback when USART1 reception is complete. It copies received data from the DMA buffer to the receive ring buffer and initiates another DMA reception if needed along with updating the ring buffer pointers and dma_rx_buffer_length variable.
Warning
This function is intended for internal use only.
