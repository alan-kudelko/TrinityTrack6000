Detailed Description

Diagnostics header for TrinityTrack6000 project. This header provides prototypes for system diagnostics functions, including memory diagnostics and overall system health checks after initialization and before entering the main application loop in main.c.

Note
All functions set global_error_code in case of failure, which can be used by Error_Handler() for debugging or startup without faulty functionalities.
All functions can be called within systemDiagnostics() or separately if needed.
